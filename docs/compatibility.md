# Совместимость

Установщик использует Python 3.9+ и стандартную библиотеку. Дополнительные Python-пакеты для установки не нужны. Git нужен для проверки индекса, если целевая папка уже является Git-репозиторием.

Основной сценарий — macOS и Linux. Windows не входит в подтверждённый сценарий этой версии: перед использованием нужны отдельные проверки экранирования команд hooks и путей. Не переносите настройки shell без проверки.

Для полного набора нужен Codex с поддержкой:

- проектного `.codex/config.toml`;
- `.codex/agents/*.toml` с `name`, `description`, `developer_instructions`;
- навыков `.agents/skills/*/SKILL.md`;
- `.codex/hooks.json`, событий `PreToolUse`, `SessionStart`, `Stop`, `PermissionRequest`;
- штатного просмотра и доверия hooks через `/hooks`.

Версия, на которой готовился пакет: `0.166.0-alpha.5.1`. Это ориентир проверок, а не гарантия совместимости всех более старых или новых сборок. Актуальные результаты смотрите в [verification.md](verification.md).

Настройки модели и доступа к аккаунту наследуются из вашей среды. Стартер не устанавливает Codex, не оформляет подписку и не добавляет API-ключ.

## Пути и перенос папки

Команды hooks генерируются установщиком для выбранной папки. После её перемещения проверьте `hooks.json`: старые абсолютные пути больше не подходят. Повторный dry-run покажет расхождения. Сравните определения и обновите пути осознанно; затем повторно просмотрите доверие через `/hooks`. Не копируйте хеши доверия из другого проекта.

## Codex и Claude вместе

Опция `--agent both` добавляет маршруты в `AGENTS.md` и `CLAUDE.md` к одному `.starter/workflow.md`. Настройки hooks и роли этого дистрибутива относятся к Codex. Опция не преобразует их в Claude hooks и не меняет существующую `.claude/`.
