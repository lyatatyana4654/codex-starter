# С чего начать

Этот архив — установщик и набор чистых шаблонов. Рабочие материалы хранятся в выбранной папке вашего проекта.

## 1. Выберите папку

Для существующего проекта используйте его текущую папку. Для нового создайте пустую. Не устанавливайте стартер в домашнюю папку целиком.

В терминале перейдите в распакованную папку `codex-starter`. В командах ниже замените `../my-project` своим путём. Путь с пробелами заключайте в кавычки.

```sh
python3 --version
python3 scripts/install_codex.py ../my-project --business --sounds
```

Нужен Python 3.9 или новее. Вторая команда — предварительный просмотр полного набора. Для минимальной установки уберите `--business --sounds` из неё и команды применения ниже. Если предварительный просмотр сообщает о конфликте, сравните указанные файлы перед установкой; не удаляйте их вслепую.

## 2. Установите набор

```sh
python3 scripts/install_codex.py ../my-project --business --sounds --apply
```

`--business` создаёт семь разделов для продуктов, аудитории, целей и другого контекста; `--sounds` подключает звуковые уведомления. Для общей папки с Claude добавьте `--agent both` в предварительный просмотр и применение.

Выберите опции сразу. `--business` не расширяет уже существующий контекст, в том числе минимальную `.business/` от прежней установки. Добавление `--sounds` после установки может вызвать конфликт конфигурации hooks; установщик не перезаписывает её автоматически.

## 3. Подключите настройки в Codex

Откройте выбранную папку проекта в приложении Codex. Если проект новый для Codex, просмотрите запрос доверия к проекту. Проверьте, что текущий режим разрешений соответствует настройкам: запись в рабочей папке, запрос при выходе за разрешённые границы.

Для проверки hooks в CLI:

```sh
cd ../my-project
codex
```

Введите `/hooks`, прочитайте команды обработчиков и подтвердите доверие нужным. Новые и изменённые определения требуют просмотра. До подтверждения hooks не считаются включёнными.

Если `/hooks` или агенты недоступны, проверьте версию Codex и [совместимость](docs/compatibility.md). Не отключайте проверки ради установки.

## 4. Начните чат

```text
Прочитай AGENTS.md, PROJECT.md и .starter/AUTOPILOT.md.
Помоги начать работу с этим проектом. Сначала изучи существующие
материалы, затем задай только вопросы, которые мешают следующему шагу.
Моя задача: [опиши желаемый результат].
```

Codex уточнит цель, сохранит согласованные вводные и подготовит подходящий план. Если код и план уже есть, продолжит их. Данные и показатели, которых нет, останутся неизвестными.

## 5. Проверьте результат

Из папки стартера выполните:

```sh
python3 scripts/doctor.py ../my-project
```

Диагностика файлов не заменяет просмотр `/hooks`. Проверка и ограничения описаны в [docs/verification.md](docs/verification.md).
