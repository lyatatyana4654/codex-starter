# Запуск проекта после установки

Рабочая инструкция устанавливается в `.starter/AUTOPILOT.md` выбранного проекта. Её исходник находится в [payload/.starter/AUTOPILOT.md](payload/.starter/AUTOPILOT.md).

Сначала выполните установку по [START_HERE.md](START_HERE.md), затем откройте целевую папку в Codex. Для разработки самого стартера действуют его корневой `AGENTS.md` и план в `plans/`.
