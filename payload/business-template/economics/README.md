# Экономика

Добавляйте раздел, когда он нужен проекту: единица расчёта, доход, переменные и постоянные затраты, период, валюта и источники исходных данных.

Каждое допущение помечайте. Отсутствующие данные не заменяйте отраслевыми числами без источника. Для некоммерческого проекта можно учитывать только время и бюджет.
