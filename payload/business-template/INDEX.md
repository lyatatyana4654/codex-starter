# Контекст проекта

Статус: чистый шаблон. Заполняйте подтверждёнными фактами и отмечайте гипотезы. Для личного или некоммерческого проекта используйте только нужные разделы.

| Раздел | Что хранить |
|---|---|
| [Компания / проект](company/README.md) | Назначение, участники, ограничения |
| [Продукты](products/README.md) | Предложение и границы результата |
| [Аудитория](audience/README.md) | Пользователи, задачи и подтверждения спроса |
| [Цели](goals/README.md) | Текущая цель, срок и критерий успеха |
| [Экономика](economics/README.md) | Допущения, доходы, затраты и источники |
| [Маркетинг](marketing/README.md) | Каналы, эксперименты и результаты |
| [Материалы](assets/README.md) | Ссылки на разрешённые рабочие источники |

В целевом проекте `.business/` предназначена для локального контекста. Проверьте `.gitignore` и Git-индекс перед заполнением. Не храните здесь ключи, пароли и персональные документы.
