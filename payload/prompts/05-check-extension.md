# Проверка внешнего расширения

```text
Проверь навык, плагин или MCP по ссылке [URL]. Сейчас только проверка,
без установки и запуска скачанных команд.
Прочитай инструкции и исполняемые файлы. Установи происхождение
и лицензию, нужные разрешения, сетевые адреса, доступ к секретам,
действия при установке и способ удаления. Отметь скрытые загрузки
и изменение глобальных настроек. Сравни это с моей задачей [задача].
Верни конкретный вывод: подходит ли расширение, какие файлы проверены,
что осталось неизвестным и что потребуется для локальной установки.
```

Если установка уже разрешена отдельным поручением, выполняйте её после проверки в этих границах. Этот запрос сам разрешает только исследование.
