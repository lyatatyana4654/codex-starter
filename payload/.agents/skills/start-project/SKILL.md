# Запуск и продолжение проекта

Прочитай `.starter/AUTOPILOT.md` относительно корня текущего проекта и выполни подходящий сценарий. Корневой `AGENTS.md` и существующие инструкции сохраняют силу.

Для продолжения найди действующий план и последнюю контрольную точку, затем сверь их с файлами и состоянием процессов. Для нового проекта используй уже доступные ответы и спроси только о пробелах, влияющих на ближайшее решение.

Результат: понятная текущая цель, сохранённые вводные в принятом месте и следующий исполнимый шаг. Если пользователь попросил только проверить или обсудить, ответь без записи файлов. Не запускай повторный онбординг для обычной задачи в уже настроенном проекте.
