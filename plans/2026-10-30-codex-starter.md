# Универсальный Codex Starter

Авторизация: пользователь просит универсальный стартер на своём GitHub, публичный репозиторий codex-starter.

## Результат
Дистрибутив без клиентских данных, с установкой в выбранную папку, правилами работы, структурой, стартовым интервью, настройками Codex, безопасными hooks, агентами и навыками. Исходный проект агентства не изменяется.

## Основа и выбор
MIT upstream artemiimillier/claude-code-starter, commit bced4fe4de21b288069a5d4b80388d9d59607218. Сохраняем LICENSE и авторство. Его консервативный установщик уже покрывает dry-run, существующие инструкции, симлинки и приватность. Добавляем обёртку Codex. Альтернативы: экспорт папки агентства содержит частные данные; новый установщик с нуля дублирует проверенную работу; простой fork без доработок не ставит hooks/settings.

## Фазы
- [x] Исследовать upstream, лицензию и актуальные форматы Codex.
- [x] Установщик: настройки и hooks в выбранной папке; предварительные проверки; отсутствие перезаписи конфликтов и глобальных изменений.
- [x] Правила, hook-защита видимых команд, контекст сеанса, необязательный звук, шаблоны ролей и навыков.
- [x] Русский запуск и интервью, библиотека промптов, шаблон бизнес-контекста и эксплуатационные документы.
- [x] Тесты, независимый разбор, smoke-test на чистой папке; проверить отсутствие частных данных и персональных абсолютных путей в публикуемых файлах.
- [x] Создать публичный GitHub-репозиторий, отправить только дистрибутив, проверить скачивание и установку.

## Критерии
Dry-run ничего не пишет. Повторный запуск идемпотентен. Конфликт настроек или symlink выявляется до записи. Существующие инструкции сохраняются. По умолчанию workspace-write/on-request; доверие hooks пользователь выдаёт штатно, без обхода. Безопасность проверяется строковыми примерами, опасные команды не выполняются. Business-контекст игнорируется Git; в публичном пакете только пустой шаблон. Настройки модели наследуются, универсальность без привязки к аккаунту. Поддержка macOS/Linux, Windows честно обозначается по проверкам.

## Итог
Реализовано: дистрибутив 0.1.0, 57 тестов, проверки навыков и состава пакета; чистая установка и нативная загрузка после штатного доверия тестовой папке. Независимый разбор выявил и помог исправить ложные успешные результаты doctor/scanner и пересечение source/target. Лицензия сохраняется также в установленной .starter/.

Опубликовано: https://github.com/lyatatyana4654/codex-starter. Владелец вошёл в GitHub, репозиторий создан через штатную форму, видимость public подтверждена API. Код отправлен обычным Git push. Проверены публичные clone и ZIP, установка из обоих источников в чистую папку и диагностика. Все четыре задания GitHub Actions #1 прошли: macOS/Linux × Python 3.9/3.13. Обязательных оставшихся шагов нет.

Особенности: installer не меняет глобальные настройки и доверие. В отдельном smoke-сеансе тестовая папка доверена штатным CLI, четыре тестовых hook оставлены недоверенными. Нативная диагностика обнаружила все три роли и два навыка. Звук не прослушивался, Windows не проверялся. Обновление/перемещение установленного проекта требует ручного сравнения конфликтов.
