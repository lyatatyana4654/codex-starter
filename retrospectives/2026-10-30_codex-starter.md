# Codex Starter 0.1.0

Цель: публичный универсальный стартер для Codex с правилами, структурой, настройками и безопасным установщиком.

Основа: MIT Claude Code Starter, исходный copyright сохранён. Использовали его консервативный установщик и добавили отдельную обёртку Codex. Приватные материалы в пакет не переносились.

Проверено: 57 тестов; формат двух навыков; Python 3.9 syntax; состав пакета; чистая установка и идемпотентность; нативная загрузка трёх ролей и двух навыков после штатного доверия тестовой папке. Независимый review проверил исправления диагностики и пересечения путей. Опасные команды не исполнялись.

Урок: наличие настроек и текстовая диагностика не доказывают нативную активацию. Профили TOML, пустые handlers, tracked-секреты и симлинки требуют отдельных отрицательных сценариев. Доверие папке и доверие hook — отдельные шаги.

Завершено: опубликован публичный репозиторий https://github.com/lyatatyana4654/codex-starter. После входа владельца в браузер создан репозиторий, код отправлен Git push. Публичные clone и ZIP проверены установкой в чистые папки. Все четыре задания GitHub Actions #1 прошли (macOS/Linux, Python 3.9/3.13). Обязательных оставшихся шагов нет. Соседние рабочие проекты не менялись.
