# Авторство и происхождение

Этот проект использует части [Claude Code Starter](https://github.com/artemiimillier/claude-code-starter) Артемия Миллера / Школы Смысло-кодинга.

Исходная версия: `bced4fe4de21b288069a5d4b80388d9d59607218`.

Заимствованная основа: консервативный установщик `scripts/install.py`, его тесты, общий процесс, шаблоны инструкций, планов и ретроспектив. Исходный copyright и полный текст MIT сохранены в [LICENSE](LICENSE).

Адаптация Codex Starter добавляет установку нативных настроек, hooks, rules, ролей, навыков и русские инструкции запуска. Изменения распространяются на условиях MIT. Исходный проект и OpenAI не заявлены авторами или гарантами этих дополнений.

Пакет содержит универсальные шаблоны. Он не содержит готовых бизнес-данных, персональных доступов, подписки Codex или лицензий на сторонние платные сервисы.
